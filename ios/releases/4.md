Device groups are now native. From Devices, tap Add, choose New Device Group, select the device whose roster should win, and pick the other handhelds that should stay in sync. Existing groups appear above independent devices with expandable, navigable member lists.

Pages load faster. Library now makes one initial request instead of four, fetches a smaller first page, and continues loading as you scroll. Recent read-only responses are reused briefly while pull-to-refresh always fetches live data. Devices and groups load together, and the server no longer builds a large selection-by-deployment join just to count games.

Cancelled searches and page transitions no longer appear as error alerts. Initial Library and Devices loads now use stable skeleton rows while their content arrives.
